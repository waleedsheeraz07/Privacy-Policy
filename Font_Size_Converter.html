Privacy Policy

Font Size Converter — px ↔ sp ↔ em  •  Effective Date: 26/04/2026

Font Size Converter is a simple, offline tool that instantly converts font size units: pixels (px), scale‑independent pixels (sp), and ems (em). Enter a value, select source and target units, and get the result immediately — no data tracking, no internet required.

🔒 Zero Data Collection
Font Size Converter does not collect, store, share, or transmit any personal or non-personal data. Your privacy is completely protected.

Information Collection and Use

The app requires no user registration and never requests personal information (name, email, phone number, location, etc.). All entered numbers (value, unit selection) are processed locally on your device and are never saved, logged, or transmitted anywhere.

Offline Functionality

Font Size Converter works entirely offline. An internet connection is not required for any feature. The app performs no network communication, API calls, or data syncing — it's just a local calculator.

Input Data (Values and Units)

The numbers and unit selections you enter exist only temporarily in your device's memory while the app is open. As soon as you close the app or navigate away, all input values are discarded. They are never:

  • Saved to internal/external storage
  • Sent to any server or cloud
  • Shared with third parties
  • Used for analytics or profiling

Copy / Paste Feature

The app includes a "Copy" button that copies the conversion result to the system clipboard. This uses the standard Android clipboard API, but the copied text is never read, logged, or transmitted by the app. The clipboard is managed entirely by the operating system, and no data leaves your device.
