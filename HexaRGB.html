Privacy Policy

HexaRGB — HEX ⇄ RGB Converter  •  Effective Date: 24/04/2026

HexaRGB is a simple, elegant app that instantly converts between HEX and RGB color formats. Enter a HEX code to get RGB values, or input RGB numbers to get the equivalent HEX — all with a live color preview. No internet connection required; everything works offline.

🔒 Zero Data Collection
HexaRGB does not collect, store, share, or transmit any personal or non-personal data. Your privacy is completely protected.

Information Collection and Use

The app does not require user registration and does not request any personal information (name, email, phone number, location, etc.). All conversions are performed locally on your device and are never saved, logged, or transmitted anywhere.

Offline Functionality

HexaRGB works entirely offline. An internet connection is not required for any feature. The app performs no network communication, API calls, or data syncing — it's just a local calculator.

Input Data (HEX Codes and RGB Values)

The HEX codes or RGB numbers you enter exist only temporarily in your device's memory while the app is open. As soon as you close the app or navigate away, all input values are discarded. They are never:

  • Saved to internal/external storage
  • Sent to any server or cloud
  • Shared with third parties
  • Used for analytics or profiling

Third-Party Services

This application does not integrate with any third-party services, SDKs, advertising platforms, analytics tools, or social media frameworks. No Facebook, Google Analytics, Firebase, or any tracking SDK is present.

Data Security

Because no data is collected, stored, or transmitted, there is zero risk of data leakage, unauthorized access, or security breaches. The app requests no runtime permissions and has no access to sensitive device features.
